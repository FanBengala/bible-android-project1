# Աստվածաշունչ — приложение для Android

Читалка Библии на армянском (восточноармянский перевод из твоего PDF «Աստվածաշունչ-արևելահայերեն»),
поиск, закладки, размер шрифта, тёмная тема, список для молитвы (имена и просьбы) и план чтения на год. Работает без интернета, текст уже внутри.

План: каждый день 3 случайных стиха из трёх разных глав, за 365 дней каждый из 1095 стихов выпадает ровно
один раз. Порядок случайный и сохраняется на устройстве. У каждого стиха своя кнопка «Կարդացի», когда нажаты
все три, день засчитывается. Как в Duolingo, растёт «комбо» (дни подряд), пропущенный день обнуляет его.

Технически это веб-приложение в оболочке Capacitor: код в `www/`, Android-проект в `android/`.

## Про текст

Текст (`www/bible-hy.json`) получен из твоего PDF. Это издание, на которое могут распространяться авторские
права, поэтому держи репозиторий на GitHub **приватным** и не рассылай APK и `bible-hy.json` другим, пока не
выяснишь, можно ли делиться этим текстом.

Чтобы заменить перевод, подготовь файл такого формата и положи его в `www/bible-hy.json`, затем пересобери:
`{"title": "...", "names": [66 названий книг], "books": [книга → глава → список стихов]}`.
Названия книг и число глав берутся из этого файла.

## Способ А. Сборка в облаке через GitHub (Android Studio не нужна)

1. Зарегистрируйся на github.com и создай новый репозиторий, выбрав **Private**.
2. Загрузи в него содержимое этой папки. Проще всего через терминал в папке проекта (нужен Git):

   ```
   git init
   git add .
   git commit -m "Bible app"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```

   Если с терминалом сложно, подойдёт программа GitHub Desktop. Убедись, что папка `.github` загрузилась.
3. В репозитории открой вкладку **Actions**, слева выбери **Build APK** и нажми **Run workflow**
   (сборка также запускается сама после каждой загрузки).
4. Через 5–10 минут сборка завершится. Открой её, внизу в разделе **Artifacts** скачай `bible-app-apk`,
   распакуй архив, внутри будет `app-debug.apk`.

## Способ Б. Сборка на компьютере через Android Studio

1. Установи [Node.js](https://nodejs.org) (22 или новее) и [Android Studio](https://developer.android.com/studio).
2. В терминале, в папке проекта:

   ```
   npm install
   npx cap sync android
   npx cap open android
   ```
3. Дождись, пока Android Studio закончит синхронизацию Gradle (внизу идёт индикатор).
4. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Готовый файл:
   `android/app/build/outputs/apk/debug/app-debug.apk`.

## Установка на телефон

1. Перенеси `app-debug.apk` на телефон (по кабелю, через Telegram «Избранное» или облако).
2. Открой файл и разреши установку из этого источника.
3. Приложение появится с названием «Աստվածաշունչ» и иконкой открытой книги.

Это отладочная сборка со стандартной подписью, для личного использования её достаточно.
Для Google Play нужна отдельная подписанная релизная сборка.

## Версия для телефона без установки

Страница `bible-web.html` не содержит текста Библии. При первом открытии она просит выбрать файл
`bible-hy.json` (он лежит в `www/`), сохраняет его в браузере телефона и дальше работает без повторного выбора.
Это запасной вариант на случай, если APK не получится собрать.

## Как получен текст

PDF хранит армянские буквы под латинскими кодами, поэтому обычное копирование даёт бессмыслицу. Скрипты в
`tools/` заменяют коды на армянские буквы и делят текст на книги, главы и стихи по номерам на полях и по
увеличенным пробелам перед началом стиха. Запуск: `pip install pymupdf`, затем
`python tools/make_bible_json.py "Աստվածաշունչ-արևելահայերեն.pdf"`. Проверено только на этом PDF.

## Что проверено и что нет

- Для Бытия, Исхода и четырёх Евангелий у меня был эталонный текст: 97,8% стихов совпали с ним полностью.
  Остальное это разночтения изданий и мелкие различия в написании, а не потеря текста.
- Остальные книги проверены только по структуре (номера стихов идут подряд, глав столько, сколько напечатано).
  Отдельные стихи там могли разобраться неточно.
- Нумерация следует печатному изданию и местами отличается от привычной: Псалмы идут по Септуагинте
  (например, «Господь — Пастырь мой» это Псалом 22), в Книге Иисуса Навина 22 главы, у Есфири 16, у Даниила 14.
  В нескольких главах нет отдельных номеров стихов, в Луки 1 в издании 59 стихов. Книги, которых нет в
  привычном каноне (Иудифь, Товит, Маккавеев, Премудрость, Сирах, Варух, 1 Ездры), в приложение не вошли.
- Не проверено: сама сборка APK и запуск на телефоне. Среда, где я работал, не может скачать Android SDK.
  Если сборка завершится ошибкой, пришли текст ошибки или скриншот.

## Текст из SQLite (ABA.SQLite3)

`tools/make_bible_from_sqlite.py` собирает `www/bible-hy.json` из файла в формате MyBible (`ABA.SQLite3`,
Արարատ Աստվածաշունչ 1910):
`python tools/make_bible_from_sqlite.py ABA.SQLite3 www/bible-hy.json <старый bible-hy.json>`
(третий аргумент нужен только для сравнения названий книг). После этого скопируй JSON и `index.html` в
`android/app/src/main/assets/public/` или просто запусти `npx cap sync android`.
